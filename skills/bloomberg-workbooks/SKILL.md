# Bloomberg workbooks

Build a workbook with explicit identifiers, field definitions and refresh status. Distinguish writing formulas from retrieving data.

## Establish the request

Identify the security universe, current versus historical observations, field definitions, units, currency, quote side and dates. For bond comparisons, separate yield, asset-swap spread, remaining maturity and loan weighted average life. They are different measures. A loan-margin comparison requires a compatible spread benchmark and units; do not subtract a bond yield from a floating-rate margin.

Inspect an existing workbook before editing. Preserve its working add-in syntax, layouts and cached returns. The bundled helper creates a new workbook; it does not edit an existing model.

## Select the formula route

- Use BDP for a current or static scalar field.
- Use BDH for historical observations, with verified date and frequency conventions.
- Use BDS for bulk results, with a reserved return area.

Verify fields and overrides in the installed Bloomberg tools. A known mnemonic does not prove that a security has coverage or that an account has entitlement. Preserve the exact function prefix generated by the installed add-in.

Read [the formula workflow](references/workflow.md) for checks and troubleshooting. Use the helper only for a BDP matrix without overrides. Other layouts require the installed add-in's generated syntax and a separate output area.

## Build the bounded demonstration

Prepare a config following [the input contract](references/config.md), then run:

```sh
python scripts/build_workbook.py examples/config.json /tmp/bloomberg-demo
```

The destination must not exist. The helper creates `workbook.xlsx` and `report.json`. It writes literal identifiers and fields on separate sheets and references them from the provider formulas. It does not fetch data or create numeric caches.

The bundled example uses invented identifiers and is labeled synthetic. For a real request, replace every identifier and field-evidence entry with reviewed inputs and set `fixture` to false. This changes the label; it does not verify the inputs. Keep the status `NOT_RUN` until a separate provider refresh has been observed.

## Refresh and review

With authorized licensed Excel access, refresh a bounded control query first. Check returned dates, units, currency, quote side and visible errors. Expand only after checking the control, then inspect all requested fields. Save and reopen in formula and value views. Do not resave a refreshed workbook with a file library merely to inspect it; that can discard formula caches.

Without that access, deliver formula construction and its checked references. State that live refresh was not run. A recalculation setting, a changed reference date or a generic spreadsheet engine does not prove Bloomberg retrieval.

Preserve errors and missing observations. Do not replace them with zero or an old quote. Only create a values-only snapshot after a successful refresh; retain the live formulas and record the observed refresh time, or state that the time is unknown.

Report the output paths, checked scope, unresolved fields and live-refresh status. Report native Excel rendering separately from package structure and formula checks.
