# Synthetic cases

Every entity, figure and source title in these cases is invented. The source references demonstrate the input contract; no real audited report is bundled or verified. The included [synthetic disclosure](synthetic-disclosure.txt) is the same source text generated by the annual [actuals planner case](../../actuals-update-planner/examples/README.md), with its SHA-256 declared in the normalized input.

From the package directory:

```sh
python scripts/analyze.py examples/complete.json --out /tmp/statement-analysis-review
python scripts/analyze.py examples/incomplete.json --out /tmp/statement-analysis-gap-review
python scripts/analyze.py examples/discrepancy.json --out /tmp/statement-analysis-difference-review
```

Each destination must be new. The complete case exits 0. The incomplete case exits 2 intentionally; it has an explicit missing lease balance and an absent FX cash movement. The discrepancy case exits 1 intentionally; its balance sheet differs by 1 reporting unit, while its reported zero OCI remains a real zero.

Committed readable outputs are in [complete-report/report.md](complete-report/report.md), [incomplete-report/report.md](incomplete-report/report.md) and [discrepancy-report/report.md](discrepancy-report/report.md). Each has its machine-readable report alongside it. Source references are included for every calculated result in JSON.

The tests use these cases and additional adversarial variants: missing/zero distinctions, invalid references and units, duplicate keys and periods, accounting failures, tolerance boundaries, zero/negative denominators, decimal precision, source changes during analysis and refusal to overwrite outputs. These checks cover the deterministic helper; agent selection and real-source transcription have not been benchmarked.
